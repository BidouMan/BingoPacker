## **🛠️ BingoPacker 智能裁切预览系统技术文档 (TDD)**

**1. 技术栈与框架选型**

为了保证“不重复造轮子”并兼顾性能，我们直接使用以下 Qt 原生核心组件：

- **视图层切换**：QStackedWidget。
- **网格布局**：QScrollArea 配合 QGridLayout（或自定义 FlowLayout 官方示例代码）。
- **图像渲染**：QGraphicsScene / QGraphicsPixmapItem（复用现有画布逻辑）。
- **数据结构**：基于 dataclasses 的轻量级对象，减少内存开销。
- **多线程处理**：QRunnable + QThreadPool（用于后台扫描像素边界，保证 UI 不卡顿）。



⠀2. 系统架构设计

**2.1 UI 层次结构 (View Hierarchy)**

在 editor_ui.py 中，将原有的 ScalableView 包装进 QStackedWidget：

1. **Index 0 (EditorView)**: 现有的 ScalableView 实例。
2. **Index 1 (ConfirmationView)**: 一个包含 QScrollArea 的 QWidget。内部使用 QGridLayout 动态生成“预览卡片”。



⠀2.2 核心数据流 (Data Flow)

1. **分析阶段**：调用 SliceLogic 返回 List[QRect]。
2. **预载阶段**：将 QRect 转换为 List[PendingFrame] 对象。
3. **显示阶段**：根据 PendingFrame 批量实例化 SliceCardWidget 并推入布局。
4. **提交阶段**：根据 SliceCardWidget 的 is_locked 状态，映射回最终的 FrameData 生成器。



⠀

**3. 核心功能实现细节**

**3.1 预览卡片 (SliceCardWidget) —— 复用与性能**

为了避免大量卡片造成的渲染压力：

- **复用机制**：继承自 QFrame，内部使用 QLabel 或 QGraphicsView 极简版显示。
- **异步加载**：使用 QPixmap.copy(rect) 裁剪子图时，在主线程切片，但“底边检测（对齐计算）”放在后台线程预跑。
- **状态管理**：内置 setProperty("selected", bool)，配合 QSS 选择器实现高亮，无需手动重画 paintEvent。



⠀3.2 辅助地平线 (Ghost Line) 的高性能实现

- **方案**：不要给每个卡片画线。
- **实现**：给 QScrollArea 的背景设置一个 **QBrush 纹理**。
- **代码策略**：利用 QPainter 绘制一个等高的透明 Tile，底部包含 1px 红线，将其设为背景。这样无论如何滚动，地平线都由 GPU 自动平铺，开销几乎为零。



⠀3.3 批量锁定逻辑 (Multi-Selection)

- **开源组件库借鉴**：参考 Qt 官方 Elastic Nodes 示例。
- **实现**：在 QScrollArea 上安装 EventFilter。
- **逻辑**：
  1. MouseButtonPress：记录起点。
  2. MouseMove：绘制 QRubberBand（Qt 原生框选控件）。
  3. MouseButtonRelease：调用 widgetAt() 或几何碰撞检测 contentsRect().intersects() 批量更新卡片状态。



⠀

**4. 性能优化策略 (Performance First)**

**4.1 内存管理**

- **延迟实例化**：只有当卡片进入 QScrollArea 的可见区域时才进行高质量渲染。
- **引用计数**：PendingFrame 只保存原始大图的引用和 QRect，不生成独立的 QImage 副本，直到用户点击“确认”为止。



⠀4.2 计算加速

- **SIMD 像素扫描**：在进行底边对齐计算（寻找非透明像素边界）时，使用 QImage.bits() 获取原始指针，采用步进扫描而非 pixelColor() 函数，性能提升可达 10 倍以上。



⠀

**5. 本地化与环境安全性**

- **零外部依赖**：所有逻辑运行在 PySide6 运行时环境内。
- **本地 I/O**：使用 QSaveFile 处理导出逻辑，确保在磁盘写入失败（如空间不足）时不会损坏原始资源库。
- **配置存储**：用户偏好（如默认是否开启锁定）记录在本地 QSettings (ini/registry) 中。



⠀

**6. 开发建议 (Cursor 指令指导)**

当你在 Cursor 中开始开发此功能时，请遵循以下指令：

1. **“请基于现有的 ManualEditor 类，通过 QStackedWidget 扩展 UI 层次，不要修改 ScalableView 的内部逻辑。”**
2. **“使用 QRubberBand 实现预览页面的框选功能，复用 Qt 原生交互机制。”**
3. **“像素边界检测逻辑请提取到单独的 QThread 类中，通过信号返回修正后的** **Y** **偏移量。”**

**技术文档结论**：本方案通过 QStackedWidget 保证了流程的完整性，通过 QRubberBand 和 QBrush 纹理复用保证了交互性能。在不引入外部重型库的情况下，完全依靠 Qt 框架能力实现“专业级”的裁切确认系统。
